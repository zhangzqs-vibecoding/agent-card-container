# M2 CodeCard 本地运行时实施计划

> 设计依据：`docs/superpowers/specs/2026-07-12-agent-card-container-design.md`。

**目标：** 完成 `.agentcard` 安装、内容寻址缓存、本地 SDK/RPC/事件、WebView 策略边界与故障隔离，使已安装 CodeCard 可离线运行。

**架构：** 主 Flutter Engine 是安装索引、SQLite、Runtime Server 与能力代理的唯一所有者。CodeCard 只运行已验证的静态 WebBundle；每个实例使用随机 origin 与短期 token，经 JSON-RPC 调用宿主能力。平台 WebView 仅通过 adapter 接入。

### Task 1：制品归档与安全校验

- [x] 先写失败测试，覆盖合法归档、超限、重复路径、绝对/父路径、符号链接、路径深度、非法入口和未知字段。
- [x] 实现受限 ZIP reader、manifest 严格解析、文件 SHA-256 校验。
- [x] 通过 Ed25519 公钥环验证规范化 manifest 签名；密钥不存在、签名错误和文件篡改必须失败。
- [x] 验证后解压到同文件系统临时目录并原子重命名到 `artifacts/sha256/<hash>`。

实现说明：加密适配层使用 libsodium；Linux 自动化加载
`libsodium.so.23`。Windows 发行物必须捆绑并校验 `libsodium.dll`，
该项与 WebView2 一并进入 Windows 设备门禁。

### Task 2：Runtime Server SDK、RPC 与隔离

- [x] 先写失败测试，覆盖动态 `/runtime/bootstrap.js`、token 不进入 URL/持久状态、严格 Host/Origin、CSP/MIME 与路径安全。
- [x] 将 RPC 方法限制为 contract 白名单，并把能力方法转发到 Capability Broker。
- [x] 增加每实例 30 次/秒、突发 60 的限流，普通响应 1 MiB 和 10 秒超时。
- [x] 实现 `/v1/events` WebSocket、单调 seq、订阅生命周期以及 suspend/resume/context 事件。

### Task 3：CodeCardHost 与 WebView adapter

- [x] 定义与平台无关的 WebViewPort 和导航/权限策略测试。
- [x] 实现 CodeCard 生命周期 mount/updateContext/suspend/resume/unmount/dispose。
- [ ] 已接入 `flutter_inappwebview` Windows WebView2 adapter，强制同源导航/资源、权限拒绝、禁下载/弹窗并在其他平台 fail-closed；仍待 Windows 实机通过随机 localhost origin 门禁后勾选完成。
- [x] 连续三次启动失败后将实例标记为 quarantined。

平台说明：依赖已从 pub.dev 解析并生成 Windows plugin registrant，但当前 Linux
构建机不能编译/运行 Windows runner。因此 WebView2 adapter 与随机 localhost 子域
仍保留为 Windows 设备门禁，不得用普通 WebView 或 path-only origin 隔离替代。

- [x] 应用按“数据库 → 安装索引 → Runtime Server → Surface”顺序启动，离线恢复 NativeCard 与 CodeCard；CodeCard 建立独立 origin、持久 storage 并交由 WebView2 adapter 挂载。
- [x] 单卡失败隔离并记录安全恢复错误，不影响其他实例和 Runtime Server 启动。
- [ ] 运行 Flutter analyze/test/build bundle 与安全回归测试。
- [ ] 记录 Linux 自动化证据及仍需 Windows 设备执行的 WebView2/origin/IME/DPI 门禁。
